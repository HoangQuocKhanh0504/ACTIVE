# 🚀 Tool Active Windows & Office - KHANHPC VIP


## 📌 Giới thiệu

**KHANHPC ACTIVE TOOL** là công cụ chuyên nghiệp giúp kích hoạt Windows và Microsoft Office một cách an toàn, nhanh chóng và không hiện popup khó chịu. Phiên bản 8.0 VIP với nhiều cải tiến vượt trội.

## ✨ Tính năng nổi bật

### 🎯 **Ưu điểm vượt trội:**
- ✅ **KHÔNG HIỆN POPUP** Windows Script Host
- ✅ Hiển thị mọi thông tin trong ứng dụng
- ✅ Tự động yêu cầu quyền Administrator
- ✅ Phóng to cửa sổ CMD fullscreen tự động
- ✅ Kiểm tra trạng thái chính xác trước/sau active
- ✅ Hỗ trợ cả Windows 10/11 và Office 2016-2021

### 🔧 **Chức năng chính:**
1. **Active Windows** - Kích hoạt Windows bằng KMS
2. **Active Office** - Kích hoạt Microsoft Office
3. **Active cả hai** - Windows + Office cùng lúc
4. **Kiểm tra trạng thái** - Xem tình trạng active hiện tại
5. **Gỡ active** - Reset lại trạng thái gốc (nếu cần)
